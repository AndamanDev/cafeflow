# คู่มือ CafeFlow แบบกดไฟล์

งานส่วนใหญ่มีไฟล์ทำให้แล้ว **ดับเบิลคลิกไฟล์ → รอ → ดูว่าขึ้นตามช่อง "ต้องเห็น" ไหม**
ไฟล์อยู่ในโฟลเดอร์ `D:\cafeflow\ops\` (เครื่องที่ไม่มีไดรฟ์ D อยู่ที่ `C:\cafeflow\ops\`)

ไม่ขึ้นตามที่เขียน → **ถ่ายรูปหน้าจอส่งช่าง** อย่าเดาทำต่อ
ต้องการวิธีทำมือทีละขั้น ดู [INSTALL-EASY.md](INSTALL-EASY.md)

---

## 1. ติดตั้งร้านใหม่ (เครื่องหลัก)

ต้องมีเน็ต · ใช้เวลา 1–2 ชม.

| ทำ | ต้องเห็น |
|---|---|
| เอาไฟล์ `install-cafeflow.bat` ใส่ Desktop ของเครื่องหลัก (ก๊อปจากแฟลชไดรฟ์) | |
| **คลิกขวา → Run as administrator** → กด **Yes** | `Programs installed. RESTART the computer now` |
| รีสตาร์ทเครื่อง → เปิด **Docker Desktop** (ปลาวาฬ) → Accept · Skip | มุมซ้ายล่าง Docker ขึ้น **Engine running** |
| **คลิกขวาไฟล์เดิม → Run as administrator** อีกครั้ง · รอ 10–30 นาที อย่าปิดหน้าต่าง | `ติดตั้งเสร็จ ✓` + **IP เครื่องนี้** → 📝 จด IP ไว้ |

- ขึ้น `✗ …` → ทำตามที่มันบอก แล้วกดไฟล์อีกครั้ง (ทำต่อจากขั้นที่ค้างเอง)
- ได้ตัวอ่านสลิปรุ่นล่าสุดอัตโนมัติ ไม่ต้องทำอะไรเพิ่ม

**ไฟล์ทำให้ไม่ได้ ต้องทำเองต่อ** (วิธีอยู่ใน [INSTALL-EASY.md](INSTALL-EASY.md)):
ขั้นที่ 4 ยกเว้นแอนตี้ไวรัส · ขั้นที่ 6 เข้า Windows เองไม่ถามรหัส · ขั้นที่ 8 BIOS ไฟมาเปิดเอง · ขั้นที่ 10.2 จอง IP ที่เราเตอร์ · ส่วนที่ 2–6 ตั้งค่าร้าน

## 2. ตั้งตู้สั่งอาหาร (คีออสก์)

| ทำ | ต้องเห็น |
|---|---|
| ก๊อป `kiosk-edge.bat` จากเครื่องหลักไปวางที่ Desktop ของตู้ | |
| คลิกขวาไฟล์ → **Edit** → แก้ `set SERVER=http://192.168.1.105:8080` เป็น **IP เครื่องหลัก** → Ctrl + S | |
| กด **Windows + R** พิมพ์ `shell:startup` → คลิกขวาลากไฟล์ไปวาง → **Create shortcuts here** | (ตู้จะเปิดหน้าสั่งอาหารเองทุกครั้งที่เปิดเครื่อง) |
| ดับเบิลคลิก `kiosk-edge.bat` | **"เครื่องนี้ยังไม่ได้จับคู่"** + รหัส 6 ตัว → ไปจับคู่ที่ หน้าภาพรวม › อุปกรณ์ |

⚠️ เปิดตู้ด้วยไฟล์นี้เท่านั้น — เปิดเว็บเองกล้องสแกนสลิปจะใช้ไม่ได้

## 3. อัปเดตเป็นเวอร์ชันใหม่

ต้องมีเน็ต · ทำตอนร้านไม่มีลูกค้า (ระบบหยุดราว 1 นาที)

| ทำ | ต้องเห็น |
|---|---|
| ดับเบิลคลิก `update-cafeflow.bat` | `OK - CafeFlow is updated and running the new version.` |

สำรองข้อมูลให้ก่อนเอง · ล้มตรงไหนจะบอกว่าต้องทำอะไร

### ⚠️ ครั้งเดียว: เครื่องที่ติดตั้งก่อน 12 ต.ค. 2569

ตัวอ่านสลิปรุ่นใหม่ต้องอัปเดตโปรแกรมเสริมเอง (`update-cafeflow.bat` ไม่ทำส่วนนี้)
ทำ **ต่อจาก** `update-cafeflow.bat` ทันที — เปิด **cmd** แล้ววางทีละบรรทัด:

```
cd /d D:\cafeflow
powershell -Command "Get-NetTCPConnection -LocalPort 5101 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }"
ocr-svc\.venv\Scripts\python.exe -m pip install -r ocr-svc\requirements.txt
ocr-svc\.venv\Scripts\python.exe -m pip list | findstr paddle
```

⚠️ ต้องขึ้นต้นด้วย `ocr-svc\.venv\Scripts\python.exe -m pip` ตามนี้เป๊ะ — **ห้ามพิมพ์ `pip install` เฉย ๆ**
(จะไปลงที่ Python หลักของเครื่องแทน · เห็น WARNING `…AppData\Roaming\Python…` = ลงผิดที่ ตัวอ่านสลิปไม่ได้อัปเดต)

✅ บรรทัดสุดท้ายต้องเห็น `paddlepaddle 3.2.2` → ดับเบิลคลิก `restart-api.bat` → สแกนสลิปที่ตู้ ผลขึ้นใน ~3 วิ
❌ เห็น `3.3.1` → บรรทัดที่ 3 ไม่สำเร็จ เช็กเน็ตแล้ววางใหม่
❌ บรรทัดที่ 3 ขึ้นว่าหา path ไม่เจอ → เครื่องนี้ยังไม่เคยลงตัวอ่านสลิป ให้ดับเบิลคลิก `D:\cafeflow\ocr-svc\setup.bat` แทน

### ⚡ ครั้งเดียว: ตัวอ่านสลิปแบบเร็ว (OpenVINO) — เครื่องที่ติดตั้งก่อน 12 ต.ค. 2569 (บ่าย)

อ่านสลิปเร็วขึ้นราว 3 เท่า (i3-6100U: 3.3 → 1.0 วิ/ใบ) · ความแม่นเท่าเดิม · ต้องมีเน็ต ~200 MB

| ทำ | ต้องเห็น |
|---|---|
| ดับเบิลคลิก `D:\cafeflow\ocr-svc\setup-openvino.bat` | `Done. Run ops\restart-api.bat to start using the fast engine.` |
| ดับเบิลคลิก `restart-api.bat` | `OK - CafeFlow API restarted with the new code.` |
| เปิดเบราว์เซอร์ที่เครื่องหลัก: `http://127.0.0.1:5101/health` | `"engine": "openvino"` |

- เคยกด `bench-ocr.bat` แล้ว = ติดตั้งไว้แล้ว ข้ามข้อแรกได้ (กดซ้ำก็ไม่เสียหาย)
- ขึ้น `OPENVINO SETUP FAILED` → ร้านยังใช้ตัวอ่านแบบเดิมได้ตามปกติ เช็กเน็ตแล้วกดใหม่
- ขึ้น `"engine": "paddleocr"` → ตัวแบบเร็วเปิดไม่ขึ้น ระบบสลับกลับตัวเดิมเอง ส่ง `logs\ocr.err.log` ให้ช่าง
- **อยากกลับไปใช้ตัวเดิม:** เปิดไฟล์ `D:\cafeflow\.env` ด้วย Notepad เพิ่มบรรทัด `CF_OCR_ENGINE=paddle` → บันทึก → `restart-api.bat`

## 4. ระบบค้าง / หน้าเว็บเข้าไม่ได้ / สลิปไม่ตรวจ

| ทำ | ต้องเห็น |
|---|---|
| ดับเบิลคลิก `restart-api.bat` | `OK - CafeFlow API restarted with the new code.` |

เปิดทุกอย่างที่ปิดอยู่ใหม่ (API · ตัวอ่านสลิป) · ยังไม่หาย → **ปิด-เปิดเครื่องหลัก** แล้วรอ 3 นาที
หน้าจอที่เปิดค้างไว้ (แคชเชียร์ · ครัว · ตู้) รีเฟรชตัวเอง

---

## 5. ล้างข้อมูลขายทดสอบ ก่อนเปิดร้านจริง

| ทำ | ต้องเห็น |
|---|---|
| ดับเบิลคลิก `clear-sales.bat` → ดูจำนวนที่จะลบ → พิมพ์ `YES` → Enter | `DONE. Refresh all screens, then open a new shift on the closing page.` |

- **ลบ:** ออเดอร์ · การชำระ · ภาพสลิป · รอบขาย · เลขคิว
- **เก็บ:** เมนู · ราคา · ผู้ใช้ · อุปกรณ์ที่จับคู่แล้ว · เครื่องพิมพ์ · ค่าตั้งทั้งหมด
- สำรองข้อมูลก่อนลบให้เอง · พิมพ์อย่างอื่นที่ไม่ใช่ `YES` = ยกเลิก
- เสร็จแล้ว: รีเฟรชทุกจอ → หน้าปิดรอบ กด **เปิดรอบ** ก่อนตู้รับออเดอร์

## สรุปไฟล์

| ไฟล์ | ใช้เมื่อ | กดยังไง |
|---|---|---|
| `install-cafeflow.bat` | ติดตั้งร้านใหม่ | คลิกขวา → Run as administrator (2 รอบ) |
| `kiosk-edge.bat` | เปิดตู้สั่งอาหาร | แก้ IP ครั้งแรก แล้วดับเบิลคลิก |
| `update-cafeflow.bat` | อัปเดตเวอร์ชันใหม่ | ดับเบิลคลิก |
| `restart-api.bat` | ระบบค้าง · หลังอัปเดตเอง | ดับเบิลคลิก |
| `clear-sales.bat` | ล้างข้อมูลทดสอบก่อนเปิดร้าน | ดับเบิลคลิก แล้วพิมพ์ YES |
| `bench-ocr.bat` | วัดว่าเครื่องนี้อ่านสลิปเร็วแค่ไหน (ช่างขอ) | ดับเบิลคลิก ตอนไม่มีลูกค้า → ถ่ายรูปผลส่งช่าง · ครั้งแรกต้องมีเน็ต |
| `ocr-svc\setup.bat` | ลงตัวอ่านสลิป (ปกติ install ทำให้แล้ว) | ดับเบิลคลิก |
