# คู่มือ CafeFlow

ระบบสั่งและขายของร้านกาแฟ: ลูกค้าสั่งเองที่ตู้ (คีออสก์) → จ่ายเงิน → ครัวทำ → จอเรียกคิว

📄 **ฉบับพิมพ์ (PDF 17 หน้า มีภาพหน้าจอจริง):** [CafeFlow-Manual.pdf](CafeFlow-Manual.pdf) — แก้เนื้อหาที่ `print/manual.html` แล้วดับเบิลคลิก `print/build-pdf.bat` สร้างใหม่ · หน้าจอเปลี่ยน: `node docs/manual/print/take-screenshots.js` ถ่ายภาพใหม่ (ไม่แตะข้อมูลจริง)

| เล่ม | เนื้อหา | ใครควรอ่าน |
|---|---|---|
| [1. สรุปการติดตั้ง](1-install.md) | ติดตั้งเครื่องหลัก ต่อจอ ตั้งร้านครั้งแรก สำรองข้อมูล | เจ้าของร้าน · ช่างที่มาติดตั้ง |
| [2. คู่มือการใช้งาน](2-usage.md) | แต่ละหน้าใช้ทำอะไร กดตรงไหน · ปัญหาที่เจอบ่อย | เจ้าของร้าน · ผู้จัดการ · แคชเชียร์ |
| [3. ลำดับการทำงาน](3-workflow.md) | ออเดอร์เดินทางยังไง ตั้งแต่ลูกค้าสั่งจนรับของ · หนึ่งวันของร้าน | ทุกคน |
| [4. บทบาท](4-roles.md) | แอดมิน · ผู้จัดการ · แคชเชียร์ · ครัว ทำอะไรได้บ้าง | ทุกคน (อ่านเฉพาะบทบาทตัวเองก็พอ) |
