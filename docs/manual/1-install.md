# 1. สรุปการติดตั้ง

> ฉบับละเอียดพร้อมคำสั่งสำหรับช่าง: [INSTALL.md](../../INSTALL.md)

## ภาพรวม

```
            ┌─────────────── Wi-Fi / สาย LAN ของร้าน ───────────────┐
            │                                                      │
  [เครื่องหลัก]  ←──  คีออสก์ (ลูกค้าสั่ง)   แคชเชียร์   จอครัว   จอเรียกคิว
  เปิดทิ้งไว้ตลอด          เครื่องพิมพ์ใบเสร็จ / ครัว (ต่อสาย LAN หรือ USB เข้าเครื่องหลัก)
```

- **เครื่องหลัก 1 เครื่อง** เก็บข้อมูลทั้งหมด ทุกจอเปิดผ่านเครื่องนี้
- **ใช้อินเทอร์เน็ตแค่ตอนติดตั้ง** หลังจากนั้นเน็ตล่มก็ขายได้ (QR พร้อมเพย์สร้างในเครื่อง)
- ทุกเครื่องต้องอยู่ในวง Wi-Fi/LAN เดียวกันของร้าน

## ของที่ต้องเตรียม

| อย่าง | รายละเอียด |
|---|---|
| เครื่องหลัก | Windows 10/11 · RAM 8 GB ขึ้นไป · ที่ว่าง 10 GB · ต่อสาย LAN |
| คีออสก์ | จอสัมผัส Windows + กล้องเว็บแคม 1080p **แบบโฟกัสอัตโนมัติ** (ไว้สแกนสลิป) |
| จออื่น ๆ | เครื่อง Windows ที่มี Edge หรือแท็บเล็ตที่มีเบราว์เซอร์ |
| ข้อมูลร้าน | ชื่อร้าน ที่อยู่ เบอร์โทร เลขผู้เสียภาษี (ถ้ามี) |
| การรับเงิน | **เบอร์/เลขพร้อมเพย์ของร้าน** · **ชื่อบัญชีตามที่ขึ้นในสลิป** · เลขบัญชีธนาคาร (4 ตัวท้ายก็ได้) — ขอเป็นข้อความ อย่าจดจากปาก |
| เมนู | รายการ ราคา ตัวเลือก (หวาน/ท็อปปิ้ง) รูปสินค้า |
| อื่น ๆ | รหัส Windows · รหัส Wi-Fi · รุ่นเครื่องพิมพ์ · มือถือที่มีแอปธนาคาร + เงิน 1 บาทไว้ทดลองโอน |

## ขั้นที่ 1 — ติดตั้งเครื่องหลัก

1. คัดลอกไฟล์ `cafeflow.bat` ลงเครื่อง แล้ว **ดับเบิลคลิก** (กด "ใช่" เมื่อถามสิทธิ์)
2. รอบแรกจะลงโปรแกรมที่จำเป็นให้เอง → เสร็จแล้ว **รีสตาร์ตเครื่อง**
3. เปิดโปรแกรม **Docker Desktop** → กด Accept → กด Skip ตอนให้ลงชื่อเข้าใช้
4. **ดับเบิลคลิก `cafeflow.bat` อีกครั้ง** → รอจนเสร็จ (ครั้งแรกนาน เพราะโหลดตัวอ่านสลิป ~1 GB)
5. จอจะบอก **ที่อยู่เครื่องหลัก** (เช่น `192.168.1.50`) — จดไว้ จะใช้ต่อจออื่น
6. บนเดสก์ท็อปจะมีไอคอน **CafeFlow** = เมนูดูแลระบบ (ดูท้ายหน้า)

ติดขัดตรงไหน รัน `cafeflow.bat` ซ้ำได้เลย ขั้นที่ทำแล้วจะข้ามไป

## ขั้นที่ 2 — ตั้งเครื่องหลักให้พร้อมขายจริง (ทำมือ)

1. ตั้งโปรแกรมแอนตี้ไวรัส **ยกเว้นโฟลเดอร์** `D:\cafeflow\ops`
2. ตั้ง Windows **เข้าสู่ระบบเองโดยไม่ต้องใส่รหัส** (ระบบเริ่มทำงานหลังเข้าสู่ระบบ)
3. ตั้ง BIOS ให้ **ไฟดับแล้วไฟมา เครื่องเปิดเอง** (Restore on AC Power Loss = Power On)
4. ตั้ง Windows Update ไม่ให้รีสตาร์ตในเวลาเปิดร้าน
5. ตั้งเราเตอร์ให้ **เครื่องหลักได้ที่อยู่เดิมเสมอ** (จอง IP)
6. **ทดสอบ:** รีสตาร์ตเครื่องโดยไม่แตะอะไร ภายใน 3 นาทีระบบต้องเปิดเองได้

## ขั้นที่ 3 — ตั้งร้านครั้งแรก

เปิด `http://ที่อยู่เครื่องหลัก:8080` เข้าด้วย **admin / demo** แล้วทำตามลำดับ (อยู่ในปุ่ม ⚙ มุมขวาบน)

1. **⚙ › ผู้ใช้และสิทธิ์** — เปลี่ยนรหัสผ่านทั้ง 4 บัญชี (admin · manager · cashier · kitchen) ห้ามใช้ `demo`
2. **⚙ › ข้อมูลร้าน**
   - ชื่อร้าน ที่อยู่ เบอร์โทร ข้อความท้ายใบเสร็จ
   - **พร้อมเพย์ของร้าน** — ตรวจทุกตัว ผิดหนึ่งตัวเงินลูกค้าเข้าบัญชีคนอื่น
   - **ตรวจสลิป:** ชื่อบัญชีผู้รับเงินตามสลิป + เลขบัญชีธนาคาร (4 ตัวท้ายก็ได้)
3. **เมนูและสินค้า** — ลบเมนูตัวอย่าง ใส่เมนูจริง ราคา รูป ตัวเลือก
4. **⚙ › ตั้งค่าคีออสก์** และ **⚙ › ตั้งค่าจอแสดงคิว** — ขนาดจอ กินที่ร้าน/กลับบ้าน เวลารอ
5. **⚙ › เครื่องพิมพ์** — เพิ่มเครื่องพิมพ์ เลือกว่าพิมพ์ให้ส่วนไหน (เคาน์เตอร์ / บาร์ / ครัว) แล้วกด **พิมพ์ทดสอบ**
   - ต้องมีเครื่องพิมพ์ "เคาน์เตอร์" อย่างน้อย 1 เครื่อง
   - เครื่องพิมพ์ต้องต่อสาย LAN หรือเสียบ USB **ที่เครื่องหลัก** (เสียบเครื่องอื่นใช้ไม่ได้)

## ขั้นที่ 4 — ต่อจออื่น

1. คัดลอกไฟล์ `screen-edge.bat` ไปไว้ที่แต่ละเครื่อง แล้วดับเบิลคลิก
2. ครั้งแรกจะถามที่อยู่เครื่องหลัก → พิมพ์ที่อยู่ที่จดไว้ (เช่น `192.168.1.50`)
3. เลือกว่าเครื่องนี้เป็นจออะไร: **1 คีออสก์ · 2 แคชเชียร์ · 3 จอครัว · 4 จอเรียกคิว**
4. จอจะเปิดเต็มจอ (ออกด้วย Alt+F4) · อยากให้เปิดเองตอนเปิดเครื่อง: `screen-edge.bat autostart`

| จอ | เข้าใช้ยังไง |
|---|---|
| แคชเชียร์ | เข้าสู่ระบบด้วยบัญชีแคชเชียร์ |
| จอครัว | เข้าสู่ระบบด้วยบัญชีครัว |
| คีออสก์ · จอเรียกคิว | **จับคู่**: จอจะขึ้นช่องใส่รหัส → แอดมิน/ผู้จัดการเปิด **⚙ › อุปกรณ์ในเครือข่าย** กด **จับคู่** ที่แถวของเครื่องนั้น → ได้รหัส 6 ตัว (ใช้ได้ 10 นาที) → พิมพ์ที่จอ · **ห้ามเข้าสู่ระบบด้วยบัญชีพนักงานที่คีออสก์** |

> ระบบมีคีออสก์ให้ 3 เครื่อง (KIOSK-01 ถึง 03) และจอเรียกคิว 1 เครื่อง

## ขั้นที่ 5 — ทดลองก่อนเปิดร้าน

1. **เปิดรอบ** ที่หน้าแคชเชียร์ (ไม่เปิดรอบ คีออสก์รับออเดอร์ไม่ได้)
2. สั่งที่คีออสก์ 1 รายการ จ่ายด้วย QR **โอนจริง 1 บาท** → สแกนสลิปที่กล้อง → ต้องเข้าครัวเอง
3. สั่งอีกรายการ จ่ายเงินสดที่แคชเชียร์ → ครัวกด **พร้อมเสิร์ฟ** → จอเรียกคิวขึ้นเลข → กด **ส่งมอบ**
4. ดูว่าใบเสร็จและสลิปครัวพิมพ์ออก
5. เมนูดูแลระบบ › **ล้างข้อมูลขาย (ก่อนเปิดร้านจริง)** — ลบออเดอร์ทดลอง เมนูและการตั้งค่ายังอยู่

## เมนูดูแลระบบ (ไอคอน CafeFlow บนเดสก์ท็อปของเครื่องหลัก)

| ใช้บ่อย | ใช้นาน ๆ ครั้ง |
|---|---|
| ตรวจสถานะระบบ | อัปเดตระบบเป็นรุ่นใหม่ (สำรองให้ก่อนเอง หยุด ~1 นาที) |
| รีสตาร์ทระบบ | ล้างข้อมูลขาย (ก่อนเปิดร้านจริง) |
| ดูที่อยู่เครื่องเซิร์ฟเวอร์ (IP) | ตั้งให้ระบบเปิดเองตอนเปิดเครื่อง |
| เปิดจอบนเครื่องนี้ | เปลี่ยนรหัสผ่านฐานข้อมูล |
| สำรองข้อมูลตอนนี้ | ติดตั้งซ้ำ / ซ่อมระบบ |

## สำรองข้อมูล

- ระบบสำรองเอง **ทุกคืน 23:30** และ **ทุกครั้งที่ปิดรอบ** เก็บไว้ 30 วันในโฟลเดอร์ `backup`
- หน้าภาพรวมจะเตือนถ้าไม่ได้สำรองเกิน 2 วัน
- แนะนำ: สัปดาห์ละครั้ง คัดลอกโฟลเดอร์ `backup` ใส่ USB เก็บไว้นอกร้าน
- เครื่องพัง/ย้ายเครื่อง: ให้ช่างทำตาม [INSTALL.md](../../INSTALL.md) หัวข้อย้ายเครื่อง
