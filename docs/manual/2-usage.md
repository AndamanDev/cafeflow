# 2. คู่มือการใช้งาน

เปิดหน้าเว็บที่ `http://ที่อยู่เครื่องหลัก:8080` · แถบบนมี **ภาพรวม · หน้าร้าน ▾ · รายงาน · เมนูและสินค้า · ⚙** (เห็นเฉพาะเมนูที่บทบาทของคุณใช้ได้)

---

## เข้าสู่ระบบ / เปลี่ยนรหัสผ่าน

- ใส่ **ชื่อผู้ใช้ + รหัสผ่าน** → ระบบพาไปหน้าของบทบาทเอง (ครัว → จอครัว · แคชเชียร์ → แคชเชียร์ · แอดมิน/ผู้จัดการ → ภาพรวม)
- อยู่ในระบบได้ 12 ชั่วโมง แล้วต้องเข้าใหม่
- **เปลี่ยนรหัสผ่าน:** กดชื่อตัวเองมุมขวาบน › เปลี่ยนรหัสผ่าน → ใส่รหัสเดิมให้ผ่านก่อน แล้วจึงใส่รหัสใหม่ (อย่างน้อย 6 ตัว ห้ามเป็น `demo` หรือชื่อผู้ใช้)
- ลืมรหัส: ให้แอดมินตั้งให้ใหม่ที่ ⚙ › ผู้ใช้และสิทธิ์

## ภาพรวม

- ยอดขายวันนี้ จำนวนบิล เงินสด/QR เทียบเมื่อวาน · กดตัวเลขเพื่อเปิดรายงานนั้น
- **ต้องจัดการ** — ดูก่อนทุกเช้า: ยังไม่เปิดรอบ · รอบเปิดค้างหลายวัน · ออเดอร์ค้างจากวันก่อน · รอตรวจการชำระ · จอหลุดการจับคู่ · ไม่ได้สำรองข้อมูล · สินค้าหมด
- ตอนนี้ในร้าน: รอชำระ / กำลังทำ / พร้อมรับ · กราฟรายชั่วโมง · ขายดี 5 อันดับ

## แคชเชียร์ (หน้าร้าน ▾ › แคชเชียร์)

ยังไม่เปิดรอบ หน้านี้จะขึ้นการ์ด **เปิดรอบ** — ใส่เงินทอนตั้งต้นแล้วกด

| แท็บ | ทำอะไร |
|---|---|
| **รอจ่าย · เงินสด** | ลูกค้าเลือกจ่ายเงินสดที่คีออสก์ → กด **รับเงินสด** → ใส่เงินที่รับ (หรือกดปุ่มแบงก์) → ระบบบอกเงินทอน → **รับชำระ** |
| **รอโอน · QR** | ลูกค้ากำลังโอนอยู่ที่คีออสก์ — ปกติไม่ต้องทำอะไร |
| **เช็กสลิป** | สลิปที่ระบบไม่แน่ใจ/ไม่ผ่าน → กด **ตรวจการชำระ** ดูภาพสลิปกับผลตรวจ (เขียว = ตรง · แดง = ไม่ตรง · เทา = อ่านไม่ออก) → เลือกเหตุผล → **ยืนยันการชำระ** หรือ **ชำระไม่สำเร็จ** |
| **กำลังทำ** | ครัวกำลังทำ — ดูอย่างเดียว |
| **พร้อมรับ** | ทำเสร็จแล้ว → **เรียกซ้ำ** (จอคิวเรียกอีกครั้ง) · **ส่งมอบให้ลูกค้า** เมื่อลูกค้ารับของ |

- ก่อนยืนยันสลิปเอง **เปิดแอปธนาคารของร้านดูว่าเงินเข้าจริง** ทุกครั้ง
- แคชเชียร์ยืนยันแทนได้ไม่เกินเพดาน (ตั้งต้น 500 บาท) เกินนั้นต้องให้ผู้จัดการยืนยัน
- แถบแดง "พิมพ์ไม่ออก" → กด **ดูและพิมพ์ซ้ำ** เลือกพิมพ์เครื่องเดิมหรือเครื่องอื่น
- กดออเดอร์เพื่อดูรายละเอียด: ใบเสร็จ · บัตรคิวซ้ำ · ส่งมอบลูกค้า

## จอครัว (หน้าร้าน ▾ › จอครัว)

- แท็บสถานี: **บาร์เครื่องดื่ม · ครัวอาหาร · เบเกอรี่ · ของหวาน** — เลือกสถานีของตัวเอง
- ตั๋วแต่ละใบมีเวลานับ: เหลือง = เกิน 3 นาที · แดง = เกิน 6 นาที
- แตะรายการเพื่อติ๊กว่าทำแล้ว → ครบทุกรายการกด **พร้อมเสิร์ฟ** (กดผิด กด **ย้อนกลับ** ได้ภายใน 5 วินาที)
- ออเดอร์มีหลายสถานี → จอคิวเรียกเมื่อ **ทุกสถานี** กดพร้อมเสิร์ฟแล้ว
- **ต้องทำรวม** = ยอดรวมแต่ละเมนูที่ค้างอยู่ · **สลิป** = พิมพ์สลิปครัวซ้ำ

## ประวัติบิล (หน้าร้าน ▾ › ประวัติบิล)

- เลือกวัน ค้นด้วยเลขออเดอร์/ชื่อเมนู · กดบิลเพื่อดูรายการ การชำระ สลิป และประวัติทุกขั้น
- พิมพ์ใบเสร็จ / บัตรคิวซ้ำ / สลิปครัวซ้ำ
- **จัดการพิเศษ** (แอดมิน/ผู้จัดการเท่านั้น ต้องใส่เหตุผลทุกครั้ง):
  - **ยกเลิก (ยังไม่ได้รับเงิน)**
  - **ยกเลิกบิลผิด/ซ้ำ** — กดผิด ออเดอร์ซ้ำ ทดสอบระบบ
  - **ยกเลิก + คืนเงินลูกค้า** — ทำผิด ไม่ได้คุณภาพ ลูกค้าขอคืน (คืนเงินให้ลูกค้าเองด้วย ระบบแค่บันทึก)

## ปิดรอบ / ปิดวัน (หน้าร้าน ▾ › ปิดรอบ/ปิดวัน)

1. **เคลียร์ออเดอร์ที่ยังไม่จบ** — ยังไม่จ่าย → ยกเลิกทั้งหมด · จ่ายแล้ว → ปิดรายการทั้งหมด · รอตรวจสลิป → ไปตรวจที่แคชเชียร์ก่อน (ยังค้างอยู่ปิดรอบไม่ได้)
2. **นับเงินสดในลิ้นชัก** แล้วใส่ตัวเลข → ระบบบอกขาด/เกิน
3. **ปิดรอบ** — เปลี่ยนกะ: เปิด "เปิดรอบใหม่ต่อทันที" · ปิดร้าน: ไม่ต้องเปิด
- ระบบสำรองข้อมูลให้หลังปิดรอบ · ดูตัวอย่างใบปิดรอบ / ส่งออก CSV ได้

## เมนูและสินค้า

- ปุ่มบน: **หมวดหมู่ · กลุ่มตัวเลือก · เพิ่มรายการสินค้า** · ปรับราคาหลายรายการ
- ฟอร์มสินค้า: ชื่อ (ไทย/อังกฤษ) · หมวด · รูป · ราคาแต่ละแบบ (ร้อน/เย็น/ปั่น — ไม่ขายแบบไหนเลือก "ไม่ขาย") · ต้นทุน · เวลาขาย · จำนวนสต็อก · สถานีที่ทำ · ตัวเลือก · เปิดขาย
- **สินค้าหมดวันนี้** — กดแล้วคีออสก์ขึ้นว่าหมดทันที
- เรียงลำดับบนคีออสก์: เลือกหมวดเดียว แล้วกดค้างที่รายการลากขึ้นลง

## รายงาน (แอดมิน/ผู้จัดการ)

เลือกช่วง วันนี้ · เมื่อวาน · 7 วัน · 30 วัน · เดือนนี้ · เลือกวัน — ส่งออก CSV ได้ทุกรายงาน
สรุปยอดขาย · ตามสินค้า · ตามหมวดหมู่ · ตามพนักงาน · ตามประเภทการชำระเงิน · ใบเสร็จรับเงิน · ตามตัวเลือกเพิ่มเติม · ความแม่นการตรวจสลิป (รายงานส่วนลดและภาษี ซ่อนไว้ แอดมินเปิดได้ที่ ⚙ › ตั้งค่าเมนู)

## ⚙ ตั้งค่า (แอดมิน/ผู้จัดการ)

| เมนู | ใช้ทำอะไร |
|---|---|
| ข้อมูลร้าน | หัวใบเสร็จ · เวลาเริ่มวันทำการ (เลขคิว A001 เริ่มใหม่) · **พร้อมเพย์** · ชื่อ/เลขบัญชีสำหรับตรวจสลิป |
| ผู้ใช้และสิทธิ์ *(แอดมิน)* | เพิ่มพนักงาน · เปลี่ยนบทบาท · ตั้งรหัสใหม่ · ปิดใช้งาน (ลบไม่ได้) · เพดานยืนยันแทนของแคชเชียร์ |
| ตั้งค่าเมนู *(แอดมิน)* | ซ่อน/แสดงและเรียงเมนูกับรายงาน |
| ตั้งค่าคีออสก์ | แนวจอ ขนาดจอ · กินที่ร้าน/กลับบ้าน · แนะนำเมนูเพิ่ม · เวลารอแต่ละหน้า · เวลานับถอยหลัง QR |
| ตั้งค่าจอแสดงคิว | ธีมสว่าง/มืด · เมนูแนะนำ · เสียง · ข้อความวิ่ง |
| เครื่องพิมพ์ | เพิ่ม/แก้เครื่องพิมพ์ · พิมพ์ส่วนไหน · พิมพ์ทดสอบ · พิมพ์ใบเสร็จอัตโนมัติ · งานที่พิมพ์ไม่ออก |
| อุปกรณ์ในเครือข่าย | สถานะแต่ละจอ · **จับคู่** คีออสก์/จอคิว |

## คีออสก์ (ฝั่งลูกค้า)

แตะจอ → กินที่ร้าน/กลับบ้าน → เลือกเมนู (แบบ ตัวเลือก จำนวน) → ตะกร้า → เลือกจ่าย
- **QR พร้อมเพย์:** ยอดใส่มาใน QR แล้ว สแกนจ่ายได้เลย → เอาสลิปในมือถือส่องกล้อง → ผ่านแล้วได้เลขคิว + บัตรคิว
- **เงินสด:** ได้เลขคิว ไปจ่ายที่เคาน์เตอร์
- ปุ่มช่วย: แก้รายการ · จ่ายเงินสดแทน · แจ้งพนักงาน · เปลี่ยนภาษา TH/EN
- QR หมดเวลา: ถามว่าโอนแล้วหรือยัง → สแกนสลิป / ขอ QR ใหม่ / จ่ายเงินสด

## จอเรียกคิว

ซ้าย = กำลังเตรียม · ขวา = พร้อมรับ (มีเสียงเตือน) · แสดงแค่เลขคิว ไม่มีชื่อหรือราคา

## ปัญหาที่เจอบ่อย

| อาการ | ทำอะไร |
|---|---|
| คีออสก์บอก "ร้านยังไม่เปิดรอบ" | เปิดรอบที่หน้าแคชเชียร์ |
| QR ออกไม่ได้ / บอกให้จ่ายที่เคาน์เตอร์ | ยังไม่ได้ใส่พร้อมเพย์ที่ ⚙ › ข้อมูลร้าน |
| สลิปขึ้น "ไม่ใช่บัญชีร้าน" ทั้งที่เงินเข้า | ใส่ชื่อบัญชี + เลขบัญชี (4 ตัวท้าย) ตามที่ขึ้นในสลิป ที่ ⚙ › ข้อมูลร้าน › ตรวจสลิป |
| สลิปอ่านไม่ออก | ให้ลูกค้าเปิดสลิปเต็มจอ ส่องให้นิ่ง หรือแคชเชียร์ตรวจเองที่แท็บเช็กสลิป |
| พิมพ์ไม่ออก | ดูกระดาษ/สาย/ไฟเครื่องพิมพ์ → แคชเชียร์กด **ดูและพิมพ์ซ้ำ** |
| จอขึ้น "ติดต่อเซิร์ฟเวอร์ของร้านไม่ได้" | ดูว่าเครื่องหลักเปิดอยู่และ Wi-Fi ต่ออยู่ · รอสักครู่ระบบต่อใหม่เอง · ไม่หาย: เมนูดูแลระบบ › รีสตาร์ทระบบ |
| คีออสก์ขึ้น "ยังไม่ได้จับคู่" | ⚙ › อุปกรณ์ในเครือข่าย › จับคู่ แล้วใส่รหัสที่จอ |
| เครื่องหลักเสียทั้งเครื่อง | จดบิลด้วยกระดาษไปก่อน แล้วโทรหาช่าง |
