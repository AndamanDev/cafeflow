ขั้นที่ 1 — ติดตั้งเครื่องหลัก

  1. เอาไฟล์ cafeflow.bat ใส่เครื่อง แล้วดับเบิลคลิก · ถ้าถามสิทธิ์ กด ใช่
  2. รอให้ลงโปรแกรมจนเสร็จ แล้วรีสตาร์ตเครื่อง
  3. เปิดโปรแกรม Docker Desktop → กด Accept → กด Skip (ไม่ต้องสมัคร)
  4. ดับเบิลคลิก cafeflow.bat อีกครั้ง · ครั้งแรกนานหน่อย (โหลดตัวอ่านสลิป ~1 GB) หน้าต่างบอก "ที่อยู่เครื่องหลัก" เช่น 192.168.1.50 — จดไว้
  5. บนหน้าจอคอมจะมีไอคอน CafeFlow = เมนูดูแลระบบ
ติดตรงไหน ดับเบิลคลิก cafeflow.bat ซ้ำได้เลย ขั้นที่ทำแล้วจะข้ามไปเอง

ขั้นที่ 2 — ตั้งเครื่องหลักให้พร้อมขาย (ช่างทำ)

🛡️ แอนตี้ไวรัสตั้งยกเว้นโฟลเดอร์ D:\cafeflow\ops
🔓 เข้าเครื่องเองตั้ง Windows ให้เปิดแล้วเข้าเองไม่ต้องใส่รหัส (ระบบเริ่มหลังเข้าเครื่อง)
🔌 ไฟดับไฟมา เปิดเองตั้งใน BIOS: Restore on AC Power Loss = Power On
🔄 Windows Updateห้ามรีสตาร์ตเองในเวลาเปิดร้าน
📍 ที่อยู่เครื่องไม่เปลี่ยนตั้งที่เราเตอร์ให้เครื่องหลักได้ที่อยู่เดิมเสมอ (จอง IP)
✅ ทดสอบรีสตาร์ตเครื่องโดยไม่แตะอะไร — ภายใน 3 นาทีระบบต้องเปิดเอง

ขั้นที่ 3 — ตั้งค่าร้านครั้งแรก

เปิดเว็บ http://ที่อยู่เครื่องหลัก:8080 → เข้าด้วยชื่อ admin รหัส demo · การตั้งค่าอยู่ที่ปุ่ม ⚙ มุมขวาบน

  1. ⚙ › ผู้ใช้และสิทธิ์ — เปลี่ยนรหัสผ่านทั้ง 4 บัญชี (admin · manager · cashier · kitchen) ห้ามใช้ demo
  2. ⚙ › ข้อมูลร้าน — ชื่อร้าน ที่อยู่ เบอร์ · เบอร์พร้อมเพย์ · ชื่อบัญชีและเลขบัญชีตามสลิป
  3. เมนูและสินค้า — ลบเมนูตัวอย่าง ใส่เมนูจริง ราคา รูป
  4. ⚙ › ตั้งค่าคีออสก์ และ ตั้งค่าจอแสดงคิว — ขนาดจอ กินที่ร้าน/กลับบ้าน
  5. ⚙ › เครื่องพิมพ์ — เพิ่มเครื่องพิมพ์ เลือกว่าพิมพ์ให้ใคร (เคาน์เตอร์/บาร์/ครัว) → พิมพ์ทดสอบ กระดาษออกจากเครื่องพิมพ์
เครื่องพิมพ์ต้องต่อสายแลน หรือเสียบ USB ที่เครื่องหลักเท่านั้น · ต้องมีเครื่องพิมพ์ "เคาน์เตอร์" อย่างน้อย 1 เครื่อง

ขั้นที่ 4 — เปิดจออื่น ๆ

  1. เอาไฟล์ screen-edge.bat ใส่ทุกเครื่อง แล้วดับเบิลคลิก
  2. ครั้งแรกจะถามที่อยู่เครื่องหลัก → พิมพ์ที่จดไว้ เช่น 192.168.1.50 แล้วกด Enter
  3. เลือกว่าเครื่องนี้คือจออะไร: 1 คีออสก์ · 2 แคชเชียร์ · 3 จอครัว · 4 จอเรียกคิว จอเปิดเต็มจอ (ปิดด้วย Alt+F4)

ขั้นที่ 5 — ทดลองก่อนเปิดร้านจริง

  1. หน้าแคชเชียร์ กด เปิดรอบ (ไม่เปิดรอบ คีออสก์รับออเดอร์ไม่ได้)
  2. สั่งที่คีออสก์ จ่ายด้วย QR โอนจริง 1 บาท → ส่องสลิปที่กล้อง ออเดอร์เข้าจอครัวเอง
  3. สั่งอีกใบ จ่ายเงินสดที่แคชเชียร์ → ครัวกด พร้อมเสิร์ฟ จอเรียกคิวขึ้นเลข + มีเสียง
  4. ดูว่าใบเสร็จและสลิปครัวพิมพ์ออก
  5. เปิดเมนูดูแลระบบ › ล้างข้อมูลขาย (ก่อนเปิดร้านจริง) — ลบออเดอร์ทดลอง เมนูและการตั้งค่ายังอยู่

รอจ่าย · เงินสดกด รับเงินสด → ใส่เงินที่รับ (หรือกดปุ่มแบงก์) → ดูเงินทอน → รับชำระ
