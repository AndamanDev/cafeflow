# 4. บทบาท — ใครทำอะไร

ทุกคนมีบัญชีของตัวเอง **ห้ามใช้บัญชีร่วมกัน** (ระบบบันทึกว่าใครกดอะไร)

---

## 👑 ผู้ดูแลระบบ (แอดมิน)

**คือ:** เจ้าของร้าน — ทำได้ทุกอย่าง
**เข้าระบบแล้วเจอ:** หน้าภาพรวม

ทำประจำ:
1. ดูหัวข้อ **ต้องจัดการ** ที่หน้าภาพรวมทุกเช้า
2. ดูรายงานยอดขาย
3. จัดการพนักงาน: เพิ่ม · ตั้งรหัสใหม่ · ปิดใช้งานคนที่ลาออก
4. แก้เมนู ราคา และการตั้งค่าร้าน

ทำได้คนเดียว: **ผู้ใช้และสิทธิ์** · **ตั้งค่าเมนู** (ซ่อน/เรียงเมนูและรายงาน)

## 🧑‍💼 ผู้จัดการร้าน

**คือ:** คนดูแลหน้าร้านแทนเจ้าของ
**เข้าระบบแล้วเจอ:** หน้าภาพรวม

ทำประจำ:
1. เปิดรอบ / ปิดรอบ นับเงิน
2. ยืนยันสลิปที่เกินเพดานของแคชเชียร์
3. **ยกเลิกบิลผิด/ซ้ำ** และ **คืนเงินลูกค้า** (แคชเชียร์ทำไม่ได้)
4. แก้เมนู ราคา ปิดสินค้าหมด · ดูรายงาน · ตั้งค่าเครื่องพิมพ์ คีออสก์ จับคู่จอ

ทำไม่ได้: จัดการผู้ใช้ · ตั้งค่าเมนู

## 💵 แคชเชียร์

**คือ:** คนประจำเคาน์เตอร์
**เข้าระบบแล้วเจอ:** หน้าแคชเชียร์

ทำประจำ:
1. **เปิดรอบ** ตอนเช้า (ใส่เงินทอน)
2. **รับเงินสด** ลูกค้าที่เลือกจ่ายเงินสด
3. **ตรวจสลิป** ที่ระบบไม่แน่ใจ — ดูแอปธนาคารร้านว่าเงินเข้าจริงก่อนกดยืนยัน
4. **ส่งมอบ** ของให้ลูกค้า · **เรียกซ้ำ** ถ้าลูกค้ายังไม่มา
5. **ปิดรอบ** ตอนเลิกกะ (นับเงินในลิ้นชัก)

ทำไม่ได้: ยืนยันสลิปเกินเพดาน (ตั้งต้น 500 บาท — ให้ผู้จัดการทำ) · ยกเลิกบิลที่จ่ายแล้ว · คืนเงิน · แก้เมนู/ราคา · ดูรายงาน

## 👨‍🍳 ครัว

**คือ:** คนทำเครื่องดื่ม/อาหาร
**เข้าระบบแล้วเจอ:** จอครัว

ทำประจำ:
1. เลือกสถานีของตัวเอง (บาร์เครื่องดื่ม / ครัวอาหาร / เบเกอรี่ / ของหวาน)
2. ทำตามตั๋ว แตะติ๊กรายการที่ทำแล้ว
3. ครบแล้วกด **พร้อมเสิร์ฟ** → จอคิวเรียกลูกค้า (กดผิด กด **ย้อนกลับ** ใน 5 วินาที)

ทำไม่ได้: รับเงิน · แก้เมนู · ปิดรอบ

## เพดานยืนยันแทน (แคชเชียร์)

- "ยืนยันแทน" = แคชเชียร์กดยืนยันว่าเงินเข้าแล้ว ทั้งที่ระบบตรวจสลิปไม่ผ่าน/ไม่แน่ใจ
- ต้องเลือกเหตุผลทุกครั้ง · ยอดเกินเพดาน ปุ่มจะกดไม่ได้ ต้องให้ผู้จัดการยืนยัน
- ตั้งต้น 500 บาท · แอดมินตั้งรายคนได้ที่ ⚙ › ผู้ใช้และสิทธิ์ › แก้ไข › เพดานยืนยันแทน
