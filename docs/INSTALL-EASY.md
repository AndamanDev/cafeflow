# คู่มือติดตั้ง CafeFlow (ฉบับง่าย)

คู่มือนี้เขียนให้คนที่ไม่ใช่โปรแกรมเมอร์ทำตามได้
**ทำทีละข้อ ตามลำดับ ห้ามข้าม** ทุกข้อจะบอกว่า:

- 👉 **ทำ** — ต้องกดอะไร พิมพ์อะไร
- ✅ **ต้องเห็น** — ถ้าทำถูก หน้าจอจะขึ้นแบบนี้
- ❌ **ถ้าไม่เห็น** — ทำอะไรต่อ

ถ้าลองแก้ตาม ❌ แล้วยังไม่ได้ **หยุดแล้วโทรหาช่าง** อย่าเดาทำต่อ
(คู่มือฉบับเต็มสำหรับช่าง: `INSTALL.md`)

ใช้เวลาประมาณ **ครึ่งวัน** · ต้องมี **อินเทอร์เน็ต** ตอนติดตั้ง (หลังติดตั้งเสร็จ ร้านขายได้โดยไม่ต้องมีเน็ต)

---

## รู้จักเครื่องในร้านก่อน

| เรียกว่า | คือเครื่องไหน | ทำหน้าที่ |
|---|---|---|
| **เครื่องหลัก** | คอมพิวเตอร์ตัวเล็ก (mini PC) วางหลังร้าน เปิดทิ้งไว้ตลอด | เก็บข้อมูลทั้งหมดของร้าน ทุกจอต่อมาที่เครื่องนี้ |
| **ตู้สั่งอาหาร (คีออสก์)** | จอสัมผัสที่ลูกค้ากดสั่งเอง | ลูกค้าสั่งและจ่ายเงิน |
| **จอแคชเชียร์** | จอที่เคาน์เตอร์ | พนักงานรับเงิน ดูออเดอร์ |
| **จอครัว** | จอในครัว/บาร์ | ดูว่าต้องทำอะไร |
| **จอคิว** | จอใหญ่ให้ลูกค้าดู | บอกเลขคิวที่เสร็จแล้ว |

> ⚠️ **ทุกเครื่องต้องต่อเน็ต/Wi‑Fi ตัวเดียวกันของร้าน** ไม่งั้นมองไม่เห็นกัน

## ก่อนออกจากบ้าน — เตรียมของ

ขอข้อมูลจากเจ้าของร้านให้ครบก่อนวันติดตั้ง:

- [ ] **เลขพร้อมเพย์ของร้าน** + ชื่อบัญชี (ให้เจ้าของร้านพิมพ์ส่งมาในแชต อย่าจดจากปากเปล่า)
- [ ] ชื่อร้าน ที่อยู่ร้าน
- [ ] รายการเมนู + ราคา + รูปสินค้า
- [ ] **รหัสผ่านเข้าเครื่องหลัก** (รหัสเปิด Windows)
- [ ] รหัสเข้าเราเตอร์ (กล่อง Wi‑Fi) — ปกติเขียนอยู่ใต้กล่อง
- [ ] เครื่องพิมพ์ใบเสร็จยี่ห้ออะไร ต่อสายแบบไหน (สายแลน / สาย USB / Bluetooth)

ของที่ต้องพกไป:
- [ ] สายแลน 1–2 เส้น
- [ ] แฟลชไดรฟ์ 1 อัน
- [ ] มือถือที่มีแอปธนาคาร + เงิน 1 บาท (ไว้ลองจ่าย QR)
- [ ] คู่มือนี้ (พิมพ์ออกมา หรือเปิดในมือถือ)

## เรื่องที่ต้องรู้ก่อนเริ่ม: วิธีเปิดหน้าต่างพิมพ์คำสั่ง

หลายข้อในคู่มือนี้ต้อง **ก๊อปคำสั่งไปวาง** ในโปรแกรมชื่อ **PowerShell** (หน้าต่างสีน้ำเงิน/ดำ)

**เปิด PowerShell แบบธรรมดา**
1. กดปุ่ม **Windows** บนคีย์บอร์ด (ปุ่มรูปหน้าต่าง)
2. พิมพ์คำว่า `powershell`
3. กด **Enter**

**เปิด PowerShell แบบผู้ดูแล (Administrator)** — บางข้อจะบอกให้เปิดแบบนี้
1. กดปุ่ม **Windows** พิมพ์ `powershell`
2. **คลิกขวา** ที่ Windows PowerShell → เลือก **Run as administrator**
3. ถ้ามีหน้าต่างถาม "Do you want to allow…" กด **Yes**

**วิธีวางคำสั่ง**
1. ในคู่มือนี้ คำสั่งจะอยู่ในกล่องสีเทา → ลากคลุมทั้งกล่อง แล้วกด **Ctrl + C**
2. ไปที่หน้าต่าง PowerShell → **คลิกขวา 1 ครั้ง** (= วาง)
3. กด **Enter** แล้ว **รอจนมันหยุดวิ่ง** และมีบรรทัด `PS C:\...>` ขึ้นมาใหม่ ค่อยทำข้อถัดไป

> 💡 ตัวหนังสือสีแดงไม่ได้แปลว่าพังเสมอไป ให้ดูที่ ✅ ของแต่ละข้อเป็นหลัก

# ส่วนที่ 1 — เครื่องหลัก

ทำทั้งหมดที่ **เครื่องหลัก** · เสียบสายแลนเข้าเราเตอร์ไว้เลย (ดีกว่า Wi‑Fi)

## ⭐ วิธีง่ายที่สุด: ไฟล์ติดตั้งอัตโนมัติ

ไฟล์ `install-cafeflow.bat` ทำ **ขั้นที่ 1, 2, 3, 5, 7 และ 10.3** ให้เอง
**กดซ้ำได้ทุกเมื่อ** — มันตรวจเองว่าลงอะไรไปแล้ว ถึงขั้นไหน แล้วทำต่อจากตรงนั้น

**เอาไฟล์มา** (เลือกอย่างใดอย่างหนึ่ง)
- ก๊อปจากเครื่องช่าง `D:\cafeflow\ops\install-cafeflow.bat` ใส่แฟลชไดรฟ์ แล้ววางบน Desktop ของเครื่องหลัก
- หรือโหลดในเครื่องหลัก: เปิด `https://raw.githubusercontent.com/AndamanDev/cafeflow/main/ops/install-cafeflow.bat` → กด **Ctrl + S** บันทึกลง Desktop

**รอบที่ 1 — ลงโปรแกรม**
1. 👉 **คลิกขวา** ที่ไฟล์ → **Run as administrator** → ถ้าถาม "Do you want to allow…" กด **Yes**
2. รอ — มันจะลง Git, Node.js, Python 3.11, Docker Desktop ให้ (เลือกรุ่นที่ตรงกับเครื่องเอง ไม่ต้องเลือก x64/ARM)

✅ **ต้องเห็น:** `Programs installed. RESTART the computer now` → **รีสตาร์ทเครื่อง**
❌ `Please right-click … Run as administrator` → ลืมคลิกขวา ทำข้อ 1 ใหม่
❌ `winget not found` → เปิด Microsoft Store ค้นหา **App Installer** กด Update/Install แล้วกดไฟล์อีกครั้ง
❌ `install failed` → เช็กเน็ต แล้วกดไฟล์อีกครั้ง

**รอบที่ 2 — หลังรีสตาร์ท**
1. 👉 เปิด **Docker Desktop** (ไอคอนปลาวาฬ) ถ้าถามให้ยอมรับเงื่อนไข กด **Accept** · ให้ Sign in กด **Skip**
2. 👉 **คลิกขวาไฟล์เดิม → Run as administrator** อีกครั้ง
3. รอ — ดาวน์โหลดโปรแกรมร้าน ตั้งฐานข้อมูล ลงตัวอ่านสลิป (**10–30 นาที** อย่าปิดหน้าต่าง)

✅ **ต้องเห็น:** `ติดตั้งเสร็จ ✓` พร้อม **IP เครื่องนี้** (📝 จดไว้ — ใช้ในขั้นที่ 10 และส่วนที่ 4) และเบราว์เซอร์เปิดหน้าเข้าสู่ระบบเอง
❌ ขึ้น `✗ …` → ทำตามข้อความที่บอก แล้ว **กดไฟล์อีกครั้ง** ขั้นที่เสร็จแล้วจะถูกข้าม
❌ ขึ้นว่า **"contains a virus or potentially unwanted software"** → ทำขั้นที่ 4 แล้วกดไฟล์อีกครั้ง

**จากนั้นทำต่อเอง:** ขั้นที่ 6 → 8 → 9 → 10.1–10.2 แล้วไปส่วนที่ 2
(ขั้นที่ 1–3, 5, 7 ด้านล่างคือวิธีทำมือ — ใช้เมื่อไฟล์อัตโนมัติไม่ผ่านเท่านั้น)

### ขั้นที่ 1 — ลงโปรแกรม 4 ตัว

ดาวน์โหลดและติดตั้งทีละตัว กด **Next** ไปเรื่อย ๆ ได้เลย ยกเว้นที่บอกไว้

| ลำดับ | โปรแกรม | ดาวน์โหลดที่ | ข้อควรระวัง |
|---|---|---|---|
| 1 | **Git** | git-scm.com | กด Next จนจบ |
| 2 | **Node.js** | nodejs.org → ปุ่ม **LTS** | กด Next จนจบ |
| 3 | **Docker Desktop** | docker.com → Download for Windows | ติดตั้งเสร็จจะให้ **รีสตาร์ทเครื่อง** → ทำตาม |
| 4 | **Python 3.11** | python.org/downloads → หาเวอร์ชัน 3.11 | ⚠️ หน้าแรก **ติ๊กช่อง "Add python.exe to PATH"** ก่อนกด Install |

**หลังรีสตาร์ท เปิด Docker Desktop** (ไอคอนรูปปลาวาฬ)
- ถ้าถามให้ยอมรับเงื่อนไข → กด **Accept**
- ถ้าให้ Sign in → กด **Skip** / ข้าม
- ถ้าบอกให้อัปเดต WSL → กดตามที่มันบอก

✅ **ต้องเห็น:** มุมซ้ายล่างของ Docker ขึ้นคำว่า **Engine running** (สีเขียว)
❌ **ถ้าไม่เห็น:** รอ 5 นาที ยังไม่ขึ้นให้รีสตาร์ทเครื่องอีกครั้ง

**เช็กว่าลงครบ** — เปิด PowerShell (แบบธรรมดา) แล้ววาง:
```powershell
git --version; node -v; docker --version; py -3.11 --version
```
✅ **ต้องเห็น:** ตัวเลขเวอร์ชัน 4 บรรทัด เช่น `git version 2.x` · `v22.x` · `Docker version 2x.x` · `Python 3.11.x`
❌ **ถ้าบรรทัดไหนขึ้นแดงว่า "not recognized":** ลงโปรแกรมตัวนั้นใหม่ แล้ว **ปิด PowerShell เปิดใหม่** ก่อนเช็กอีกรอบ

### ขั้นที่ 2 — ลงโปรแกรมร้าน

เปิด PowerShell (แบบธรรมดา) แล้ววางทีละกล่อง **รอให้แต่ละกล่องเสร็จก่อน**

**กล่องที่ 1 — ดาวน์โหลดโปรแกรมร้านลงไดรฟ์ D**
```powershell
cd D:\
git clone https://github.com/AndamanDev/cafeflow.git
cd D:\cafeflow
Copy-Item .env.example .env
```
✅ มีโฟลเดอร์ `D:\cafeflow` เกิดขึ้น
❌ ถ้าขึ้นให้ login GitHub → ใส่บัญชีที่ช่างให้มา · ถ้าเครื่องไม่มีไดรฟ์ D → โทรหาช่าง

**กล่องที่ 2 — สร้างฐานข้อมูล** (ต้องเปิด Docker ไว้)
```powershell
cd D:\cafeflow
docker compose up -d db
```
✅ ขึ้นคำว่า **Started** หรือ **Running**
❌ ถ้าขึ้นว่า `cannot connect` / `docker daemon` → Docker ยังไม่เปิด กลับไปดูขั้นที่ 1

**กล่องที่ 3 — ติดตั้งและใส่ข้อมูลตั้งต้น** (ใช้เวลา 2–5 นาที)
```powershell
cd D:\cafeflow\api
npm ci
npm run migrate
npm run seed
```
✅ บรรทัดท้าย ๆ ไม่มีคำว่า **ERR!** หรือ **Error**
❌ มี Error → ถ่ายรูปหน้าจอส่งช่าง

> ⚠️ กล่องที่ 3 ทำ **ครั้งเดียวเท่านั้น** ถ้าทำซ้ำหลังร้านเริ่มขายแล้วอาจมีปัญหา

### ขั้นที่ 3 — ลงตัวอ่านสลิป

1. 👉 เปิดโฟลเดอร์ `D:\cafeflow\ocr-svc`
2. 👉 ดับเบิลคลิกไฟล์ **setup.bat**
3. รอ — จะโหลดของประมาณ 900 MB (10–30 นาที ขึ้นกับเน็ต)

✅ **ต้องเห็น:** คำว่า **Done** แล้วหน้าต่างให้กดปุ่มใดก็ได้เพื่อปิด
(ไม่ต้องดับเบิลคลิก start.bat ตามที่มันบอก — ขั้นที่ 5 จะตั้งให้เปิดเอง)
❌ ขึ้นว่า **SETUP FAILED** → เช็กเน็ตแล้วดับเบิลคลิก setup.bat ใหม่ · ถ้าบ่นว่าไม่เจอ Python → ลง Python ใหม่ และ **อย่าลืมติ๊ก Add to PATH**

### ขั้นที่ 4 — บอกโปรแกรมป้องกันไวรัสว่าไม่ต้องบล็อก

โปรแกรมป้องกันไวรัสมักเข้าใจผิดว่าโปรแกรมเปิดร้านอัตโนมัติเป็นไวรัส แล้วลบทิ้งเงียบ ๆ ต้องบอกมันก่อน

**ถ้าเครื่องใช้ Windows Security (ไม่มีโปรแกรมป้องกันไวรัสตัวอื่น):**
1. 👉 กดปุ่ม Windows พิมพ์ `Windows Security` → Enter
2. 👉 กด **Virus & threat protection**
3. 👉 ใต้หัวข้อ "Virus & threat protection settings" กด **Manage settings**
4. 👉 เลื่อนลงล่างสุด หา **Exclusions** → กด **Add or remove exclusions** → **Yes**
5. 👉 กด **Add an exclusion** → **Folder** → เลือก `D:\cafeflow\ops` → **Select Folder**

✅ เห็น `D:\cafeflow\ops` อยู่ในรายการ
**ถ้าเครื่องมีโปรแกรมป้องกันไวรัสตัวอื่น** (เช่น Avast, ESET, Kaspersky): เปิดโปรแกรมนั้น หาเมนู **Exclusions / ข้อยกเว้น** แล้วเพิ่มโฟลเดอร์เดียวกัน

เปิด PowerShell (แบบธรรมดา) แล้ววาง:

node D:\cafeflow\ops\install-autostart.js

✅ **ต้องเห็น:** `ตั้งแล้ว: Task Scheduler → CafeFlow`
❌ ขึ้นว่า **Access denied** → ปิดหน้าต่าง เปิด PowerShell **แบบผู้ดูแล (Run as administrator)** แล้ววางใหม่
❌ ขึ้นว่า **"contains a virus or potentially unwanted software"** → ขั้นที่ 4 ยังไม่สำเร็จ กลับไปทำใหม่

### ขั้นที่ 6 — ให้เครื่องเข้า Windows เองโดยไม่ต้องใส่รหัส

ถ้าไฟดับแล้วเครื่องเปิดเอง จะได้ไม่ค้างที่หน้าใส่รหัส

**6.1 ปิดตัวเลือก Windows Hello** (Windows 11 ต้องทำก่อน ไม่งั้นข้อ 6.2 จะไม่มีช่องให้ติ๊ก)
1. 👉 กดปุ่ม Windows พิมพ์ `Sign-in options` → Enter
2. 👉 หาข้อ **"For improved security, only allow Windows Hello sign-in…"** → กดให้เป็น **Off**

**6.2 เอาการใส่รหัสออก**
1. 👉 กดปุ่ม **Windows + R** พร้อมกัน → พิมพ์ `netplwiz` → Enter
2. 👉 **เอาติ๊กออก** ที่ช่อง "Users must enter a user name and password to use this computer"
3. 👉 กด **OK** → ใส่รหัสผ่าน Windows 2 ครั้ง → **OK**

### ขั้นที่ 7 — ห้ามเครื่องหลับ

เปิด PowerShell (แบบธรรมดา) แล้ววาง:
```powershell
powercfg /change standby-timeout-ac 0; powercfg /change hibernate-timeout-ac 0; powercfg /change disk-timeout-ac 0
```
✅ ไม่มีอะไรขึ้นเลย = สำเร็จ

**ตั้งไม่ให้ Windows อัปเดตแล้วรีสตาร์ทตอนร้านเปิด**
1. 👉 กดปุ่ม Windows พิมพ์ `Windows Update settings` → Enter
2. 👉 **Advanced options** → **Active hours** → เลือก **Manually** → ใส่เวลาเปิด–ปิดร้าน

---

### ขั้นที่ 8 — ไฟมาแล้วให้เครื่องเปิดเอง (ตั้งใน BIOS)

> ข้อนี้ยากที่สุด ถ้าไม่มั่นใจ **ข้ามไปก่อนแล้วแจ้งช่าง** ร้านยังใช้ได้ แค่ไฟดับแล้วต้องมีคนกดเปิดเครื่องเอง

1. 👉 รีสตาร์ทเครื่อง ระหว่างที่จอเพิ่งติด **กดปุ่ม Delete หรือ F2 รัว ๆ**
2. 👉 จะเข้าหน้าตั้งค่าสีฟ้า/ดำ (ใช้เมาส์ไม่ได้ ใช้ลูกศรบนคีย์บอร์ด)
3. 👉 หาเมนูชื่อประมาณ **Restore on AC Power Loss** / **After Power Failure** / **AC Power Recovery**
   (มักอยู่ในหมวด Power, Advanced หรือ Chipset)
4. 👉 เปลี่ยนเป็น **Power On** / **On**
5. 👉 กด **F10** → เลือก **Yes** (บันทึกแล้วออก)

### ขั้นที่ 9 — ทดสอบเปิดเครื่องใหม่

1. 👉 รีสตาร์ทเครื่อง **แล้วไม่ต้องแตะอะไรเลย** รอ 3 นาที
2. 👉 เปิดเบราว์เซอร์ (Edge / Chrome) พิมพ์ที่ช่องด้านบน: `localhost:8080/app/login.html`

✅ **ต้องเห็น:** เครื่องเข้า Windows เองโดยไม่ถามรหัส และเว็บขึ้น **หน้าเข้าสู่ระบบ CafeFlow**
❌ **ค้างที่หน้าใส่รหัส Windows** → ขั้นที่ 6 ยังไม่สำเร็จ
❌ **เว็บขึ้นว่าเข้าไม่ได้** → รออีก 2 นาทีแล้วกดรีเฟรช ยังไม่ได้ให้เปิดไฟล์ `D:\cafeflow\logs\start.log` ถ่ายรูปบรรทัดล่าง ๆ ส่งช่าง

### ขั้นที่ 10 — ให้เครื่องอื่นในร้านมองเห็นเครื่องหลัก

**10.1 หาเลขประจำเครื่อง (IP)**
เปิด PowerShell แล้วพิมพ์ `ipconfig` กด Enter → หาบรรทัด **IPv4 Address** เช่น `192.168.1.105`

📝 **จดเลขนี้ไว้** — ต่อไปในคู่มือจะเรียกว่า **IP เครื่องหลัก**

**10.2 ล็อกเลขนี้ไว้ไม่ให้เปลี่ยน** (ตั้งที่เราเตอร์)
ถ้าเลขเปลี่ยน ทุกจอในร้านจะหาเครื่องหลักไม่เจอ
- เข้าหน้าตั้งค่าเราเตอร์ (ดูที่อยู่และรหัสใต้กล่องเราเตอร์ มักเป็น `192.168.1.1`)
- หาเมนู **DHCP Reservation / Static Lease / Address Reservation / จองไอพี** แล้วจองเลขของเครื่องหลักไว้
- หน้าตาแต่ละยี่ห้อไม่เหมือนกัน ถ้าหาไม่เจอ **ถ่ายรูปหน้าจอเราเตอร์ส่งช่าง**

**10.3 เปิดทางให้เครื่องอื่นเข้ามา** — เปิด PowerShell **แบบผู้ดูแล (Run as administrator)** แล้ววาง:
```powershell
New-NetFirewallRule -DisplayName "CafeFlow 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private
```
แล้วตั้งเน็ตของเครื่องเป็นแบบ **Private**:
กดปุ่ม Windows พิมพ์ `Network status` → Enter → กด **Properties** ของเน็ตที่ต่ออยู่ → เลือก **Private network**

**10.4 ทดสอบจากมือถือ** (มือถือต้องต่อ Wi‑Fi ร้าน)
เปิดเบราว์เซอร์ในมือถือ พิมพ์ `http://IP เครื่องหลัก:8080/api/health` เช่น `http://192.168.1.105:8080/api/health`

✅ **ต้องเห็น:** ข้อความที่มีคำว่า `"ok":true`
❌ เข้าไม่ได้ → เช็กว่ามือถือต่อ Wi‑Fi ร้านจริง และทำข้อ 10.3 ครบ

# ส่วนที่ 2 — ตั้งค่าร้าน (ทำจากเครื่องไหนก็ได้)

เปิดเบราว์เซอร์ไปที่ `http://IP เครื่องหลัก:8080/app/login.html`
เข้าด้วยชื่อ **admin** รหัส **demo**

1. **เปลี่ยนรหัสผ่าน** — ระบบจะบังคับเปลี่ยนตอนเข้าครั้งแรก
   แล้วไปเมนู **ผู้ใช้และสิทธิ์** เปลี่ยนรหัสให้ครบทุกบัญชี จนแถบสีเหลือง "ยังใช้รหัสตั้งต้น" หายไป
   📝 จดรหัสแต่ละบัญชีไว้ให้เจ้าของร้าน
2. **ข้อมูลร้าน** (หน้าภาพรวม › ข้อมูลร้าน) — ชื่อร้าน ที่อยู่
3. **เลขพร้อมเพย์** — ก๊อปจากแชตที่เจ้าของร้านส่งมา **อย่าพิมพ์เอง**
   ⚠️ ผิดตัวเดียว เงินลูกค้าเข้าบัญชีคนอื่น · ใส่ **ชื่อบัญชีผู้รับเงิน** ให้ตรงกับที่ขึ้นบนสลิปด้วย
4. **เมนูและสินค้า** — ลบเมนูตัวอย่าง ใส่เมนู ราคา รูป ของร้านจริง
5. **ตั้งค่าคีออสก์** — แนวจอ (ตั้ง/นอน) · กินที่ร้าน/กลับบ้าน

# ส่วนที่ 3 — เครื่องพิมพ์ใบเสร็จ

ตั้งที่ **หน้าภาพรวม › เครื่องพิมพ์ › เพิ่มเครื่องพิมพ์**

| เครื่องพิมพ์ต่อแบบ | ทำอย่างไร |
|---|---|
| **สายแลน** (แนะนำ) | พิมพ์หน้าทดสอบจากตัวเครื่องพิมพ์ (มักกดปุ่ม Feed ค้างตอนเปิดเครื่อง) จะเห็น IP ของเครื่องพิมพ์ → เลือกแบบ **LAN** ใส่ IP นั้น พอร์ต **9100** |
| **สาย USB** | เสียบที่ **เครื่องหลัก** · ลงไดรเวอร์ของยี่ห้อนั้นจนเครื่องพิมพ์ขึ้นใน Windows → เลือกแบบ **USB** แล้วเลือกชื่อเครื่องพิมพ์จากรายการ |
| **Bluetooth** | ยุ่งกว่า — ให้ช่างทำ (ดู `INSTALL.md` ข้อ 7.1) |

แต่ละเครื่องพิมพ์ตั้ง:
- **ใช้พิมพ์ของส่วนไหน** — เคาน์เตอร์ / บาร์ / ครัว · **ต้องมีอย่างน้อย 1 เครื่องเป็นเคาน์เตอร์**
- **ขนาดกระดาษ** — วัดกระดาษในเครื่อง 58 หรือ 80 มม.
- เครื่องพิมพ์ที่อยู่ข้างตู้สั่งอาหาร ต้องต่อแบบ **สายแลน** เท่านั้น

✅ **ทดสอบ:** สั่งออเดอร์ 1 ใบแล้วกดรับเงิน → ใบเสร็จต้องออกที่เคาน์เตอร์ และใบสั่งต้องออกที่ครัว/บาร์
❌ พิมพ์ไม่ออก / ตัวหนังสือขอบขวาขาด → ลองเปลี่ยน **ความละเอียด** (เครื่อง Epson TM-T88 เลือก 180 dpi)

# ส่วนที่ 4 — จอหน้าร้าน

### ตู้สั่งอาหาร (คีออสก์)

**ติดกล้อง** (ไว้สแกนสลิปจากมือถือลูกค้า)
- ติดระดับอก หันหาลูกค้า **ก้มกล้องลงนิดหน่อย**
- **ห้ามมีหลอดไฟหรือหน้าต่างอยู่ด้านหลังลูกค้า** ตรงแนวกล้อง (แสงจะสะท้อนจอมือถือ อ่านสลิปไม่ได้)

**ตั้งให้เปิดหน้าสั่งอาหารเอง**
1. 👉 ก๊อปไฟล์ `D:\cafeflow\ops\kiosk-edge.bat` จากเครื่องหลัก ใส่แฟลชไดรฟ์ ไปวางที่ **หน้าจอ (Desktop)** ของตู้
2. 👉 **คลิกขวา** ที่ไฟล์ → **Edit** (หรือ Open with › Notepad)
3. 👉 หาบรรทัด `set SERVER=http://192.168.1.105:8080` → แก้เลขให้เป็น **IP เครื่องหลัก** → กด **Ctrl + S** บันทึก

5. 👉 **คลิกขวาลาก** ไฟล์ kiosk-edge.bat จากหน้าจอไปปล่อยในโฟลเดอร์นั้น → เลือก **Create shortcuts here**

✅ **ต้องเห็น:** หน้าจอเต็มขึ้นว่า **"เครื่องนี้ยังไม่ได้จับคู่"** พร้อมรหัส 6 ตัว

> ⚠️ เปิดตู้สั่งอาหารด้วยไฟล์ kiosk-edge.bat **เท่านั้น** (ถ้าเปิดเว็บเองกล้องจะใช้ไม่ได้)
> ⚠️ **ห้ามเข้าระบบด้วยบัญชีพนักงาน** บนตู้สั่งอาหาร
> 💡 จะออกจากหน้าเต็มจอ: กด **Alt + F4**
